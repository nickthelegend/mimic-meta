# MIMIC audit

Local app only. The repo has no deployed URL. The planned server is `uvicorn server:app` on 127.0.0.1 port 8730. The final Phase 2 run used **http://127.0.0.1:55508** after the 8730 bind check reported it unavailable. One page: GET / serves `web/index.html`. No on-chain contracts. No MCP tools. CLIs are `python -m mimic.synth` and `python -m mimic.pipeline`.

Phase 2 completed every formerly PENDING row in real Chrome for Testing, through the local HTTP server, or with `.venv/bin/python` for CLI rows. Final counts: **31 PASS, 7 FAIL, 4 UNTESTED**. Each browser log includes console, page errors and network activity; expected HTTP errors still fail a browser row when Chrome logs a console error. Fix cells remain empty. UNTESTED rows are unchanged. Evidence is under `audit/` (2.5 MB); the heavy slot was released and all started server/browser processes were cleaned up. See [run metadata](audit/run.json), [process cleanup](audit/processes.json), and [runner](audit/run_audit.py).
